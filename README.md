# Pong Game

A classic Pong game implementation using HTML5 Canvas and JavaScript.

## Features

- Two-player gameplay
- Smooth paddle and ball physics
- Score tracking
- Simple and responsive controls
- Beautiful gradient background and neon styling

## How to Play

1. Open `index.html` in your web browser
2. **Player 1 (Left paddle):** Use `W` and `S` keys to move up and down
3. **Player 2 (Right paddle):** Use `Up Arrow` and `Down Arrow` keys to move up and down
4. Press `Space` to start/pause the game
5. Press `R` to reset the game and scores

## Game Rules

- The ball bounces off the top and bottom walls
- Players score a point when the opponent fails to hit the ball back
- The ball speeds up after each paddle hit for increased difficulty
- First to reach a target score wins!

## Controls

| Key | Action |
|-----|--------|
| W | Player 1 - Move Up |
| S | Player 1 - Move Down |
| ↑ | Player 2 - Move Up |
| ↓ | Player 2 - Move Down |
| Space | Start/Pause |
| R | Reset Game |

## Installation

No installation required! Simply download the files and open `index.html` in any modern web browser.

## Files

- `index.html` - Game HTML structure
- `style.css` - Game styling and layout
- `script.js` - Game logic and mechanics

## Browser Compatibility

Works on all modern browsers that support HTML5 Canvas and ES6 JavaScript.
